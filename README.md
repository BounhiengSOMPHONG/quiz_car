# Driving Quiz App

แอปทำแบบทดสอบขับรถ (ภาษาไทย/ลาว) — React + Vite + Express

## การรัน

### โหมดพัฒนา (แนะนำ)

```bash
npm install
npm run dev
```

เปิด http://localhost:5173 — API ถูกฝังอยู่ใน Vite dev server แล้ว (ไม่ต้องเปิด server แยก)

### โหมดใช้งานจริง

```bash
npm run build
npm start        # http://localhost:3000 (เปลี่ยนพอร์ตได้ด้วย PORT=xxxx)
```

> หมายเหตุ: `npm run preview` ไม่มี API (ใช้เฉพาะ `start`)

## บัญชีทดสอบ

| ผู้ใช้ | รหัสผ่าน | บทบาท |
| --- | --- | --- |
| admin | admin123 | แก้ไขคำถาม/รูป, แดชบอร์ด |
| tester | test123 | ทำข้อสอบ 30 ข้อ + โหมดฝึกซ้อม |

แก้ไขบัญชีได้ที่ `public/users.json`

## ฟีเจอร์

- **Admin (`/admin/quiz`)** — แก้ไขคำถาม ตัวเลือก คำตอบที่ถูก คำอธิบาย หมวดหมู่ และอัปโหลด/ลบรูปได้ บันทึกลงไฟล์ JSON จริงทันที (มี backup ทุกครั้ง)
- **Tester** — หน้าแรกมีปุ่ม "เริ่มแบบทดสอบ 30 ข้อ" (สุ่มคำถาม สลับตัวเลือก ตรวจถูก/ผิดเมื่อส่ง แล้วดูรีวิวทีละข้อ) + "โหมดฝึกซ้อม" (ดูเฉลยทันที) + ประวัติการสอบ
- **แดชบอร์ด admin (`/admin`)** — สถิติคำถาม/หมวดหมู่ และคะแนนของผู้ใช้แต่ละคน

## ไฟล์ข้อมูล (อยู่นอกโฟลเดอร์โปรเจกต์)

- ข้อมูลคำถาม: `../driving_questions_I_to_XI_all_correct_added.json` (โฟลเดอร์ `q_car/`)
- รูปภาพ: `../image/` (ตั้งชื่อตามรหัสข้อ เช่น `q001.png`)
- Backup อัตโนมัติ: `../backup/` (timestamped เก็บล่าสุด 20 ไฟล์)

## API

- `GET /api/questions` — ข้อมูลทั้งหมด
- `PUT /api/questions/:id` — แก้ไขข้อ (`image: {dataUrl}` อัปโหลดรูป / `null` ลบรูป / ไม่ส่ง = คงเดิม)
- `POST /api/questions` — เพิ่มข้อใหม่ (ระบบกำหนด `id` และ `number` ให้)

## ข้อจำกัดที่ทราบ

- API ไม่มีระบบยืนยันตัวตน (ระดับความปลอดภัยเท่ากับไฟล์ static เดิม) — เหมาะใช้ในวง LAN/เครื่องเดียว
- กำลังทำข้อสอบแล้วรีเฟรชหน้า = ข้อสอบเริ่มใหม่ (ยังไม่บันทึกข้อสอบค้างไว้)
- คำตอบและประวัติการสอบเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น
